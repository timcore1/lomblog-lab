## 🎯 Что это

Учебный стенд для курса по этичному хакингу. Минималистичный блог на Flask, в котором «случайно» забыли про безопасность. Твоя задача — найти все уязвимости и собрать флаги формата `TIMCORE{...}`.

Подходит для:

- 📚 лабораторных работ по веб-безопасности
- 🚩 тренировки перед CTF
- 🎓 демонстрации OWASP Top 10 на пальцах

## 🚀 Quickstart

**Docker (рекомендуется):**

```bash
git clone https://github.com/timcore1/lomblog-lab.git
cd lomblog-lab
docker build -t lomblog .
docker run --rm -p 5001:5001 lomblog
```

**Локально:**

```bash
pip install -r requirements.txt
python app.py
```

Открывай http://127.0.0.1:5001 — и в бой. Прокси на Burp Suite / ZAP настраивается по вкусу. 😎

## 📁 Структура

```
lomblog-lab/
├── app.py              # весь стенд — один файл (~810 строк)
├── requirements.txt    # flask, и всё
├── Dockerfile          # python:3.12-slim, multi-arch
└── README.md
```

Один файл — не баг, а фича: код читается за 10 минут, каждая уязвимость помечена комментарием. Идеально для разбора на паре.
