## 🎯 Что это

Учебный стенд для курса по этичному хакингу. Минималистичный блог на Flask, в котором «случайно» забыли про безопасность. Твоя задача — найти все уязвимости и собрать флаги формата `TIMCORE{...}`.

Подходит для:

- 📚 лабораторных работ по веб-безопасности
- 🚩 тренировки перед CTF
- 🎓 демонстрации OWASP Top 10 на пальцах

## 🗺️ Задания

| # | Таск | Категория | Сложность |
|---|------|-----------|-----------|
| 1 | Прочитай чужой профиль | Broken Access Control (IDOR) | ⭐ |
| 2 | Заставь блог выполнить твой JS | Stored XSS | ⭐⭐ |
| 3 | Войди в админку без пароля | Слабая криптография сессий | ⭐⭐⭐ |
| 4 | Найди «забытый» бэкап | Information Disclosure | ⭐ |
| 5 | Вытащи флаг из чужой таблицы через поиск | SQL-инъекция (UNION-based) | ⭐⭐⭐ |
| 6 | Заставь страницу приветствия выполнить твой шаблон | SSTI (Jinja2) | ⭐⭐⭐⭐ |
| 7 | Выберись из папки с материалами курса | Path traversal | ⭐⭐⭐ |
| 8 | Подделай JWT и попади в админ-API | JWT: слабый секрет / alg=none | ⭐⭐⭐⭐ |
| 9 | Заставь сервер сходить на служебный адрес | SSRF (превью ссылок) | ⭐⭐⭐⭐ |
| 10 | Накрути лайки в обход «один лайк на сессию» | Race condition (TOCTOU) | ⭐⭐⭐⭐⭐ |
| 11 | 👑 Босс-файт: пройди цепочку XSS → кука → SSTI → флаг | Kill chain | 👑👑👑👑👑 |

Дыр больше, чем заданий — бонусы тем, кто смотрит шире списка. 😉

Таск 8 живёт в мини-API: `POST /api/login` выдаёт JWT, `GET /api/admin/flag` его проверяет. Подпись HS256 — присмотрись к секрету (jwt_tool со словарём или hashcat -m 16500) и к тому, что бывает, если библиотека доверяет полю `alg` из токена.

Таск 9 — «превью ссылок» на странице поста: `GET /preview?url=...` ходит по указанному адресу от имени сервера. Служебный `/internal/metadata` снаружи «недоступен» — но только потому, что о нём никто не знает. Попроси сервер сходить туда сам.

Таск 10 — лайки под постами. Кнопка «❤️» пускает один лайк на сессию, но помнит об этом только cookie, а счётчик обновляется не атомарно. Постучись в `POST /like/<id>` сотней параллельных запросов с одной и той же сессией — и загляни в `/flag/race`.

### 👑 Таск 11 — босс-файт

Финальный таск не про одну дыру, а про цепочку из четырёх. По стенду ходит **бот-модератор**: раз в 30 секунд он открывает новые комментарии от своего лица. Если в комментарии лежит XSS — скрипт исполняется уже в контексте бота, а его кука сессии открывает служебный `/moderate/import` («импорт шаблона поста»), где пользовательский текст рендерится через `render_template_string`. Дальше — SSTI и чтение файла с флагом рядом с `app.py`.

Шаги для студента:

1. оставить комментарий со скриптом, уводящим `document.cookie` на `/collect?c=...`;
2. подождать полминуты и забрать куку модератора из панели `/collect`;
3. подставить куку в браузер/`curl` и открыть `/moderate/import`;
4. через SSTI (`{{7*7}}` для проверки) прочитать файл с флагом.

Флаг босса не засчитывается «по кусочкам»: без куки модератора шаг 3 закрыт, а без XSS куку не достать. Пароля у учётки модератора нет — только через бота.

## 🚀 Quickstart

**Docker (рекомендуется):**

```bash
git clone https://github.com/timcore1/lomblog-lab.git
cd lomblog-lab
docker build -t lomblog .
docker run --rm -p 5001:5001 lomblog
```

**Локально:**

```bash
python -m venv .venv && source .venv/bin/activate   # на Kali/Parrot обязателен
pip install -r requirements.txt
python app.py
```

> На Kali/Parrot/Debian системный `pip` отвечает `externally-managed-environment` (PEP 668). Варианты: venv выше либо `pip install --user --break-system-packages -r requirements.txt`.

Открывай http://127.0.0.1:5001 — и в бой. Прокси на Burp Suite / ZAP настраивается по вкусу. 😎

Проверка тасков и цепочки босса:

```bash
python -m pytest -q                        # все таски
python tests/chain_demo.py                 # живой прогон таска 11 по HTTP
```

Бот-модератор таска 11 поднимается вместе с приложением (в том числе под `flask run` и в Docker). Для отладки его поведение управляется переменными окружения: `LOMBLOG_BOT=0` — не запускать, `LOMBLOG_BOT_INTERVAL` — интервал в секундах (по умолчанию 30), `LOMBLOG_BOT_BASE` — адрес стенда, по которому ходит бот.

## 📁 Структура

```
lomblog-lab/
├── app.py              # весь стенд — один файл (~1450 строк)
├── requirements.txt    # flask, PyJWT, requests
├── Dockerfile          # python:3.12-slim, multi-arch
├── tests/              # таски 8–11 + живучесть старых векторов
└── README.md
```

Один файл — не баг, а фича: код читается за 10 минут, каждая уязвимость помечена комментарием. Идеально для разбора на паре.
